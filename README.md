# НУБіП. Тваринництво — сайт виставки (EXPO NUBIP)

Статичний односторінковий сайт (HTML + CSS + JS), без бази даних і без збірки. Працює на GitHub Pages.

## Структура

```
index.html            — уся сторінка
css/style.css         — стилі
js/config.js          — НАЛАШТУВАННЯ (дата, логотипи, посилання, GitHub-авто)
js/main.js            — логіка (меню, таймер, логотипи, галерея)
images/logo/          — логотип сайту (logo.svg)
images/hero/          — фонові зображення верхнього екрана (див. README у папці)
images/gallery/       — фото для галереї
images/team/          — фото команди
images/social/        — (резерв) власні іконки соцмереж
logos/general-partners/ — генеральні партнери
logos/partners/         — партнери
logos/sponsors/         — спонсори
logos/participants/     — учасники
logos/info-partners/    — інформаційні партнери
```

## Як додати логотип

1. Покладіть файл (PNG/SVG/JPG/WebP) у потрібну папку `logos/...`.
2. Додайте рядок у `js/config.js`:
   `{ file: "company.png", name: "Назва", url: "https://company.com" }`

Або увімкніть автопідхоплення: у `config.js` встановіть `github.enabled: true`, вкажіть `owner`, `repo`, `branch` — тоді всі зображення з папок підтягуватимуться самі (публічний репозиторій).

## Публікація на GitHub Pages

1. Створіть репозиторій на github.com і завантажте вміст цієї папки в корінь.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `/ (root)`.
3. Сайт буде за адресою `https://<owner>.github.io/<repo>/`.

## Що потрібно замінити

У `index.html` позначено `TODO`: цифри, опис, експозиція, програма, команда, адреса, телефон.
Дату таймера задайте в `js/config.js` (`eventDate`).
Іконки соцмереж — спрощені вбудовані SVG; за потреби замініть на офіційні.

## Фірмовий стиль (брендбук НУБіП України v1.0.1)

| Елемент | Значення |
|---|---|
| Основний синій | `#0061AB` (CMYK 100,60,0,0) · відтінки 50/25/10 %: `#7FB0D5` `#BFD7EA` `#E5EFF7` |
| Основний жовтий | `#FFEF00` (CMYK 0,100,0,0) |
| Додаткові | білий, чорний `#1D1D1B`, сірий `#DADADA`, зелений `#00934A`, червоний `#E30613`, рудий `#E28E04` |
| Градієнти | синій `#0F3F78 → #0061AB → #0F3F78`, жовтий `#A39C00 → #FFEF00 → #A39C00` |
| Шрифти | Myriad Pro (веб, інформаційні матеріали) і Minion Pro (наукові тексти); на сайті — відкриті аналоги Source Sans 3 / Source Serif 4 з Google Fonts, запасні Arial / Times New Roman |
| Логотип | `images/logo/logo.svg` (основний), `logo-white.svg`, `logo-blue.svg`, `logo-yellow.svg`, `logo-black.svg` — векторні, витягнуті з брендбуку |
| Візерунок | `images/hero/pattern.svg` — щити у шаховому порядку (стор. 42 брендбуку) |

Усі кольори й шрифти задані змінними на початку `css/style.css`.
Правила з брендбуку: логотип не розтягувати й не перефарбовувати; на фото — лише на синій або жовтій плашці; на синьому тлі використовувати основний варіант або білий монохромний.
Щоб використати оригінальний Myriad Pro, ліцензовані файли додайте самі й підключіть через `@font-face` у `css/style.css`.

## Порожні папки
У папках `logos/*`, `images/gallery`, `images/team`, `images/social` лежать файли `README.txt`, щоб GitHub зберіг папки. Видаліть їх, коли додасте перші зображення.
