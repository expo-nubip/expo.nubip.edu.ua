# Фонові зображення верхнього екрана (hero)

Браузер автоматично вибирає файл залежно від ширини екрана, орієнтації та щільності пікселів (1x / 2x).
Покладіть сюди файли з такими іменами (формат JPG; можна замінити на WebP, змінивши розширення в `index.html`):

| Файл                  | Для кого                                  | Рекомендований розмір |
|-----------------------|-------------------------------------------|-----------------------|
| `hero-mobile.jpg`     | телефони (до 767 px), 1x                  | 800 × 1400            |
| `hero-mobile@2x.jpg`  | телефони з Retina-екраном, 2x             | 1600 × 2800           |
| `hero-tablet.jpg`     | планшети (768–1279 px), 1x                | 1280 × 1000           |
| `hero-tablet@2x.jpg`  | планшети 2x                               | 2560 × 2000           |
| `hero-desktop.jpg`    | ноутбуки/ПК (1280–2199 px), 1x            | 1920 × 1080           |
| `hero-desktop@2x.jpg` | ПК із 2x-екраном                          | 3840 × 2160           |
| `hero-wide.jpg`       | великі/ультраширокі екрани (від 2200 px)  | 2560 × 1440           |

Якщо файлів немає, сайт показує зелений градієнт.
Вага кожного файлу — бажано до 400–500 КБ (стискайте, напр. squoosh.app).
